# CU Battlecode

Welcome to the development repository for the Chandigarh University (CU) Battlecode programming competition. 
This project is built upon the MIT Battlecode engine and Galaxy infrastructure.

## Directory Structure

* `battlecode26/` - Original upstream MIT Battlecode 2026 engine and client (DO NOT MODIFY DIRECTLY).
* `galaxy/` - Original upstream MIT Galaxy platform (DO NOT MODIFY DIRECTLY).
* `cu-battlecode-game/` - CU fork of the Battlecode engine. Contains our custom game mechanics, maps, and visualizer tweaks.
* `cu-battlecode-platform/` - CU fork of the Galaxy platform. Contains our frontend, backend, and infrastructure logic.
* `cu-battlecode-scaffold/` - The starter template for participants to write their Java bots.
* `cu-battlecode-docs/` - Comprehensive documentation for developers, organizers, and participants.
